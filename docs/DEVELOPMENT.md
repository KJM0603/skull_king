`C:\Users\SSAFY\Documents\Codex\skull_king`을 유일한 개발 폴더로 사용합니다. werewolf와는 별도 Git 저장소이며, 그 프로젝트의 비밀 값이나 운영 설정은 사용하지 않습니다.

## 명령

2026-10-29 룰북/시간 변경 버전은 <http://localhost:4181/>에서 실행합니다. 사용자가 4180에서 게임을 진행 중이어서 해당 프로세스를 종료하지 않고 최신 소스를 4181에서 별도로 실행했습니다. 두 서버의 방은 서로 공유하지 않습니다. 4180의 기존 실행 중인 게임은 기존 45초 규칙이며, 새 20초/15초 규칙으로 시작하려면 4181을 사용합니다. 기본 실행 포트는 계속 4180이고, 진행 중인 게임이 끝난 뒤 해당 포트의 서버를 최신 소스로 재시작하면 새 규칙을 적용할 수 있습니다.

```powershell
cd C:\Users\SSAFY\Documents\Codex\skull_king
npm start
npm test
```

`npm start`는 서버가 실행되는 동안 유지됩니다. 다른 터미널에서 테스트를 실행해 주세요. `.env.example`은 참고용이며 자동으로 읽지 않습니다. 설정 변경은 셸에서 환경 변수를 지정합니다.

```powershell
$env:PORT = '4181'
npm start
```

기본 바인딩은 로컬 전용 `127.0.0.1`입니다. 같은 네트워크에서 개발 확인이 필요하면 `HOST=0.0.0.0`을 셸 환경 변수로 지정하고 PC의 LAN 주소로 접속할 수 있습니다. 현재 단계는 운영용 공개 서비스가 아닙니다.

초대 링크의 `127.0.0.1`은 다른 기기에서 접속할 수 없습니다. 추후 외부 HTTPS 주소를 구성한 뒤 지인 초대에 사용합니다. 브라우저 보안 환경에 따라 링크 복사가 차단되면 화면의 방 코드를 전달하시면 됩니다.

## 접속할 수 없을 때

첫 확인 주소는 <http://localhost:4180/>입니다. 서버가 실행 중이어야 열립니다. `start-local.cmd` 또는 `npm start`로 실행한 창을 닫으면 서버도 종료됩니다. `localhost` 접속이 어려운 경우 <http://127.0.0.1:4180/>도 확인합니다.

2026-10-29 접속 요청 시 서버가 종료된 상태임을 확인하고, 별도의 숨김 백그라운드 Node.js 프로세스로 다시 실행했습니다. 해당 서버는 채팅 작업 완료 후에도 유지합니다. 재부팅하면 자동으로 시작하지 않습니다. 로그는 Git에서 제외된 `.local/server-4180.stdout.log`, `.local/server-4180.stderr.log`에 있으며, 실행 시 기록한 PID는 `.local/server-4180.pid`에 있습니다. PID 파일은 과거 값일 수 있으므로 중지 전 포트 소유자와 프로세스를 다시 확인합니다. 이미 서버가 실행 중이면 중복 실행하지 않습니다.

```powershell
Invoke-RestMethod http://localhost:4180/api/health
Get-NetTCPConnection -LocalPort 4180 -State Listen
```

정상 서버는 `project: skull_king`, `ok: true`를 응답합니다.

## 소스 구조

| 위치 | 역할 |
| --- | --- |
| `server.mjs` | HTTP 서버, 고정 정적 파일 목록, API |
| `src/lobby.mjs` | 서버 소유의 방·참가자·인증·준비 상태 |
| `src/game.mjs` | 기본 덱·셔플·규칙·점수·손패 필터·규칙 기반 AI |
| `public/game-ui.js` | 게임 진행·카드 선택·예측·결과 화면 |
| `public/` | 한국어 화면과 대기실 상태 갱신 |
| `tests/lobby.test.mjs` | 임의 포트에 실제 서버를 열어 다중 참가자 흐름 검증 |
| `tests/bots.test.mjs` | AI 추가/삭제 권한, 인간과 AI 정원, 방장 승계, 빈 방 정리 검증 |
| `tests/game.test.mjs` | 특수 카드·색 따르기·점수·전체 게임·타임아웃·이탈 대체 검증 |
| `tests/game-http.test.mjs` | 실제 HTTP로 시작·비공개 정보·제출 오류·전체 게임·다시 하기 검증 |

대기실의 **＋ AI 플레이어 추가**는 방장에게만 표시됩니다. AI는 참가 인증 토큰을 발급하지 않는 서버 소유 참가자이며 자동으로 준비 완료 상태가 됩니다. 일반 참가자는 서버 API로도 AI를 조작할 수 없습니다. AI는 자신의 손패와 공개된 트릭만 보고 예측하고 합법적인 카드를 냅니다. 기본 지연은 650ms이며 트릭 결과는 1800ms 표시합니다. 실제 화면은 1초 간격으로 동기화하므로 여러 AI 행동이 한 번에 표시될 수 있습니다.

기본 모드는 3~8명입니다. 혼자라면 **AI와 바로 시작**, 이미 3명 이상이라면 **게임 시작**을 누릅니다. 방장 자신은 준비 여부와 무관하게 시작할 수 있으며 다른 사람은 모두 준비해야 합니다. 예측은 20초, 카드 제출은 차례마다 15초 후 자동 행동합니다. 라운드 결과에서 방장이 다음 진행을 선택합니다.

제한 시간은 `src/game.mjs`의 `BID_TIMEOUT_MS`와 `PLAY_TIMEOUT_MS`에서 정의합니다. 새 라운드 예측, 예측 완료 후 첫 차례, 각 후속 차례, 다음 트릭의 첫 차례마다 해당 제한을 적용합니다. 상태 응답의 `game.timeLimits`로 화면 안내를 맞춥니다. 이전 서버와 함께 확인할 때는 이 필드가 없는 게임의 안내를 기존 45초로 유지합니다.

첫 화면/대기실의 **처음이라면 · 룰북 읽기**, 게임 중 간단 규칙의 **예시와 함께 자세한 룰북 읽기**가 같은 네이티브 대화상자를 엽니다. 앞부분의 **카드는 총 몇 장인가요?**에서 기본 모드 70장의 종류별 장수, 색마다 1~14의 숫자 구성과 중복 수를 확인할 수 있습니다. 확장·안내 카드는 별도로 구분합니다. 닫기와 Esc를 지원하며, 입력이나 카드 선택을 다시 렌더링하지 않습니다. 원문은 `public/index.html`에 있고 점수/카드/시간 변경 시 함께 갱신합니다. 정적 HTML 변경은 서버 재시작 없이 새로고침으로 반영됩니다.

게임 요청에는 게임 ID, 라운드 번호, 카드 제출 시 트릭 번호를 함께 보내 이전 판/라운드의 지연 요청을 거부합니다. 오류 시 선택을 보존하며 새 진행 상태를 조회합니다. 조회 시작 이후 행동 요청이 발생하면 오래된 조회 응답을 화면에 적용하지 않습니다.

현재 대기실과 게임 상태 공유는 1초 간격 HTTP 조회입니다. 서버 이벤트 전송 또는 WebSocket은 후속 개선 항목입니다. 이름은 HTML이 아닌 텍스트로 출력하고, 참가 인증 토큰은 URL과 공개 방 상태에 넣지 않습니다. 상대 손패와 미공개 예측은 응답에서 제외하며, 화면은 진행 상태만 갱신될 때 입력 폼과 손패 버튼을 다시 생성하지 않습니다.

방은 브라우저 탭 단위 참가 정보로 복원됩니다. 여러 참가자 검증에는 새 탭에서 주소를 직접 열거나 별도의 브라우저 프로필을 이용합니다. 탭 복제 시 브라우저가 sessionStorage까지 복사할 수 있습니다.

## Git과 배포

원격 `origin`은 <https://github.com/KJM0603/skull_king.git>입니다. 개발은 `dev`에서 진행하고, 검증한 변경을 `origin/dev`에 푸시합니다. `main` 병합은 사용자의 요청이 있을 때 진행합니다.

```powershell
git status
git switch dev
git push -u origin dev
```

GitHub 푸시와 외부 서버 반영은 별도로 확인합니다. 현재 외부 운영 서버에는 배포하지 않았습니다. 이 프로젝트를 Codex 사이드바의 프로젝트로 등록하려면 이 폴더를 프로젝트로 열어 주세요. 폴더 생성 자체가 사이드바 등록을 뜻하지는 않습니다.

## 인터랙티브 인게임 UI

2026-10-29 카드 테이블 UI는 서버 재시작 없이 새로고침으로 적용됩니다. 최신 게임 규칙을 사용하는 주소는 <http://localhost:4181/>입니다. 진행 중인 사용자의 서버와 방을 유지하며, UI 변경에는 `public/index.html`, `public/style.css`, `public/game-ui.js`를 사용합니다.

- 손패는 탭/클릭으로 선택하여 설명을 확인합니다. 자신의 차례에 빛 테두리가 있는 카드를 선택하고 **내기**로 확정합니다. 선택만으로 제출하지 않으며 대기 중 또는 낼 수 없는 카드도 설명은 확인할 수 있습니다.
- 모바일에서는 손패를 좌우로 밀어 확인합니다. 카드 선택·포커스·스크롤은 진행 상태 갱신 시 유지합니다. 키보드는 Tab과 Enter/Space로 조작합니다.
- 예측 숫자 버튼과 숫자 입력은 같은 값을 사용합니다. **예측 확정** 뒤에는 수정할 수 없습니다.
- SVG 카드 문양과 CSS 전장/카드 효과는 외부 자산 없이 동작합니다. `prefers-reduced-motion`에서는 착지·승리·타이머·차례 전환 효과를 줄입니다.
- `tests/game-ui.test.mjs`는 DOM 대역으로 예측과 선택 보존, 서버 허용 카드만 제출 활성화, 응답 대기/재시도, 같은 트릭의 승자 갱신, 라운드/방 초기화를 확인합니다. 실제 브라우저 레이아웃 검증과는 구분합니다.

브라우저 레이아웃은 320px, 390px, 1440px 폭에서 확인했습니다. 실물 휴대전화 터치와 운영 서버 배포는 별도 검증이 필요합니다.
