## 2026-10-29 · 선택 취소·드래그 제출·고정 원탁 좌석

- 선택한 손패를 다시 누르면 선택과 티그리스 조작부가 해제됩니다. 선택만으로 제출하지 않으며 기존 내기 버튼도 유지합니다.
- 마우스/펜/터치 Pointer Events로 카드를 끌어 원탁 안에 놓으면 기존 제출 API를 한 번 호출합니다. 미리보기 카드와 제출 영역 강조를 표시합니다. 테이블 밖·타원 바깥 모서리·좌석 위 드롭은 제출하지 않습니다.
- 내 차례·서버 허용 카드·요청 대기·마감 시각을 확인합니다. 끄는 동안 차례/트릭/라운드가 바뀌거나 Esc, pointercancel, 포인터 캡처 해제, 화면 전환이 발생하면 취소합니다. 드롭 이후 합성 클릭으로 선택이 다시 바뀌지 않게 처리합니다. 실패 시 선택을 유지하여 재시도합니다.
- 터치의 좌우 이동은 손패 스크롤, 위쪽 이동은 카드 드래그로 구분합니다. 티그리스는 먼저 선택하고 방식을 정한 뒤 끌어 놓거나 내기 버튼으로 제출합니다.
- 서버가 게임 시작 때 암호학적 난수로 좌석을 한 번 섞습니다. `seatOrder`는 모든 참가자에게 같고 게임 내내 고정됩니다. 1번 좌석부터 시작하고 실제 차례는 좌석의 시계 방향으로 진행합니다. 각 라운드 시작은 한 자리씩 회전하며 트릭 승자가 다음 트릭을 시작합니다.
- 좌석·제출 카드를 원탁 둘레/해당 좌석 앞에 고정 배치합니다. 방향 화살표, 현재 차례와 다음 참가자, 마지막 차례 안내를 표시합니다. 기존 중앙 5초 카운트다운을 보존했습니다.
