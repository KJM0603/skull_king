## 검증

- `npm test`: 6개 테스트 통과. 실제 HTTP 서버에서 8명 입장, 정원 초과, 준비 동기화, 이름 중복, 잘못된 요청/인증, 방장 승계, 빈 방 정리와 정적 파일 응답을 확인했습니다.
- `node --check server.mjs`, `node --check public/app.js`: 통과했습니다.
- 브라우저 두 탭에서 빈 이름 오류, 초대 링크의 코드 입력, 방 생성/참가, 다른 참가자의 준비 표시, 새로고침 복원, 방장 퇴장 후 승계를 확인했습니다.
- 데스크톱 대기실 화면을 확인했습니다. 브라우저 크기 변경이 실제 뷰포트에 반영되지 않아 모바일 크기 검증과 물리적 휴대전화 검증은 미완료입니다.
- 실행 환경의 기본 네트워크 제한으로 최초 로컬 HTTP 테스트가 EACCES로 차단되었으며, 허용된 로컬 통신 환경에서 다시 실행해 통과했습니다. 인앱 브라우저 확인에는 `http://localhost:4180/`을 사용했습니다.

외부 저장소 연결과 배포는 진행하지 않았습니다. 검증용 서버는 종료하며 사용 시 `npm start` 또는 `start-local.cmd`로 실행합니다.
