- 외부 패키지가 필요 없는 Node.js 개발 환경 및 실행 파일 구성

- 참가자별 인증과 공개 상태 분리, 새로고침 복원, 잘못된 요청 검증

게임 시작·손패·예측·카드 제출·승패·점수·채팅·음성·영상은 아직 구현 전입니다. 기본 규칙과 선택 확장의 범위를 확인한 뒤 게임 엔진부터 진행합니다.

## 검증

- `npm test`: 6개 테스트 통과. 실제 HTTP 서버에서 8명 입장, 정원 초과, 준비 동기화, 이름 중복, 잘못된 요청/인증, 방장 승계, 빈 방 정리와 정적 파일 응답을 확인했습니다.
- `node --check server.mjs`, `node --check public/app.js`: 통과했습니다.
- 브라우저 두 탭에서 빈 이름 오류, 초대 링크의 코드 입력, 방 생성/참가, 다른 참가자의 준비 표시, 새로고침 복원, 방장 퇴장 후 승계를 확인했습니다.
- 데스크톱 대기실 화면을 확인했습니다. 브라우저 크기 변경이 실제 뷰포트에 반영되지 않아 모바일 크기 검증과 물리적 휴대전화 검증은 미완료입니다.
- 실행 환경의 기본 네트워크 제한으로 최초 로컬 HTTP 테스트가 EACCES로 차단되었으며, 허용된 로컬 통신 환경에서 다시 실행해 통과했습니다. 인앱 브라우저 확인에는 `http://localhost:4180/`을 사용했습니다.

외부 저장소 연결과 배포는 진행하지 않았습니다. 검증용 서버는 종료하며 사용 시 `npm start` 또는 `start-local.cmd`로 실행합니다.

## 2026-10-29 · 대기실 AI 플레이어 추가

- 방장 전용 **＋ AI 플레이어 추가**와 AI별 **삭제** 버튼을 추가했습니다. AI는 자동으로 준비합니다.
- AI도 전체 8명 정원에 포함합니다. 정원이 차면 추가 버튼이 비활성화되며 서버도 초과 요청을 거부합니다.
- AI 이름은 사람과 다른 AI의 이름을 피해 부여합니다. AI에는 참가 인증 토큰을 발급하지 않습니다.
- 일반 참가자의 관리 요청, 사람 또는 다른 방의 AI 삭제 요청을 서버에서 거부합니다.
- 방장 승계 시 AI는 제외합니다. 마지막 사람이 퇴장하면 AI가 남아 있어도 방을 정리합니다.
- 참가자 행을 재사용하여 준비 상태 갱신 시 삭제 버튼과 입력 포커스를 유지합니다.
- `npm test`: 기존 대기실 및 AI HTTP 검증을 합쳐 13개 통과했습니다. JavaScript 구문 검사와 `git diff --check`도 통과했습니다.
- 브라우저에서 AI 7명 추가, 8명 정원과 버튼 비활성화, 삭제 후 재추가, 새로고침 복원, 일반 참가자에게 관리 버튼 숨김을 확인했습니다.
- 기존 서버를 확인한 뒤 최신 소스로 재시작했습니다. 메모리 방식으로 인해 이전 대기실은 초기화되었으며, 기존 이름으로 새 방을 만들고 AI 3명을 추가한 상태로 화면과 서버를 유지합니다.

현재 AI는 대기실 테스트용입니다. 카드 게임 진행과 AI의 자동 카드 플레이는 아직 구현 전이며, 별도의 AI 서비스나 API 키를 사용하지 않습니다. GitHub `dev` 푸시와 로컬 서버 반영을 진행하며 외부 운영 배포는 하지 않습니다.

## 2026-10-29 · 실제 게임 시작과 기본 게임 완주

대기실만 제공하여 시작할 수 없었던 문제를 해결했습니다. 앞선 대기실/AI 단계의 제한 사항은 아래 구현으로 대체합니다.

- 방장 **게임 시작**, 1인 **AI와 바로 시작** 추가. 혼자 시작하면 AI를 채워 4명으로 구성합니다. 방장은 별도로 준비할 필요가 없고 다른 사람만 준비를 확인합니다.
- 기본 카드 70장, 비공개 손패, 동시 예측 공개, 순차 카드 제출, 색 따르기, 인어/해적/스컬킹/티그리스 판정 구현.
- 기본 점수와 포획 보너스, 라운드 결과, 10라운드 합계/공동 1위 연장, 같은 방 다시 하기 구현.
- AI는 자신의 손패와 공개 정보만 사용해 예측·합법 카드 선택을 합니다. 예측/차례 45초 만료 시 사람도 자동 행동하며, 게임 중 나가면 AI로 대체합니다.
- 서버는 게임 ID·라운드·트릭을 확인해 중복/지연 요청과 잘못된 카드 제출을 거부합니다. 손패/비공개 예측은 다른 참가자에게 전송하지 않습니다.
- 화면은 진행 중 입력과 카드 선택을 보존하며, 행동 전에 시작된 오래된 조회 응답은 적용하지 않습니다.
- 공식 영문 규칙서 2024 본문을 확인했으며 상세 적용 범위는 `docs/RULES.md`에 기록했습니다. 지원 범위는 3~8명 기본 모드이며 2인 전용과 확장 옵션은 미지원입니다.

검증:

- `npm test`: 22개 통과. 실제 HTTP에서 시작 권한/준비, 비공개 예측, 잘못된 제출, 전체 게임 종료, 점수 합계, 같은 방 다시 시작을 검증했습니다.
- 규칙 엔진에서 색 따르기, 특수 카드 순환/선착, 티그리스, 14/포획 보너스, 0 예측, 정원별 배분, 타임아웃과 이탈 대체를 검증했습니다.
- 브라우저에서 1인 AI 바로 시작, 손패, 예측 제출, 카드 선택/내기, AI 자동 행동, 실제 획득과 점수, 다음 라운드와 게임 중 나가기를 확인했습니다. 새로고침/모바일 실기기 범위는 기존 검증과 별도로 판단합니다.

사용자용 4180 서버를 최신 게임 소스로 재시작했으며 계속 실행합니다. 사용자 탭에는 기존 이름과 AI 3명의 새 대기실, **게임 시작** 버튼을 준비했습니다. 별도 브라우저 검증 방은 퇴장 후 정리했습니다. 개발 브랜치는 `dev`이며 외부 운영 배포는 진행하지 않습니다.
