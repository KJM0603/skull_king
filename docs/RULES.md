- 공식 규칙/FAQ: https://www.grandpabecksgames.com/pages/skull-king

현재 단계에서는 카드 규칙을 코드로 구현하지 않았습니다. 적용할 판본, 기본 덱, 선택 규칙과 확장을 확인한 뒤 이 문서를 명세로 확장합니다. 공식 안내 페이지 확인은 전체 규칙서 검토 완료를 의미하지 않습니다.

## 구현 전 확인 항목

- 라운드 수와 배분 장수, 인원별 처리, 첫 선과 다음 선 결정
- 모두 제출할 때까지 각자의 예측을 비공개로 유지하는 방식
- 숫자 카드의 색 따르기와 특수 카드를 낼 수 있는 조건
- 도망·해적·인어·스컬킹·티그리스 선택의 상호작용
- 모두 도망인 트릭, 동급 특수 카드, 여러 특수 카드 조합
- 기본 점수, 0 예측, 보너스와 예측 적중 조건
- 크라켄·흰고래·전리품·해적 능력 등의 적용 여부와 확장 구분

## 서버 구현 원칙

클라이언트는 선택을 요청하고 서버가 허용 여부와 결과를 결정합니다. 손패는 본인에게만, 미공개 예측은 공개 시점 이후에만 전달합니다. 셔플은 서버의 암호학적 난수를 사용하고, 차례가 아닌 제출·소유하지 않은 카드·색 따르기 위반·중복 제출은 서버에서 차단합니다.

라운드 종료 후 전체 점수와 계산 근거를 보여주고, 게임 진행 중 다른 사람의 남은 손패는 공개하지 않습니다. 규칙 엔진은 HTTP 및 UI와 분리하여 카드 조합과 전체 게임 진행을 자동 검증합니다.
