구판 인쇄용 규칙서는 인어/스컬킹 보너스 처리와 다른 부분이 있어 구현 기준으로 혼용하지 않습니다. 최신 규칙서와 공식 FAQ에서 일치하는 기본 규칙을 사용하며 확장 카드의 서로 다른 해석은 이번 구현 범위에서 제외합니다.

## 인원과 진행

- AI를 포함해 3~8명. 2인 전용 고스트는 미구현이므로 시작 전에 AI를 추가합니다. 혼자 **AI와 바로 시작**을 누르면 총 4명으로 구성합니다.
- 기본 모드는 총 **70장 = 숫자 56장 + 특수 14장**입니다. 확장 카드와 실물 제품의 안내 카드는 이 합계에 포함하지 않습니다.

  | 카드 종류 | 숫자 / 구성 | 장수 |
  | --- | --- | --- |
  | 초록 숫자 | 1~14, 숫자마다 1장 | 14장 |
  | 노랑 숫자 | 1~14, 숫자마다 1장 | 14장 |
  | 보라 숫자 | 1~14, 숫자마다 1장 | 14장 |
  | 검정 숫자 | 1~14, 숫자마다 1장 | 14장 |
  | 도망 | 숫자 없음 | 5장 |
  | 해적 | 숫자 없음 | 5장 |
  | 인어 | 숫자 없음 | 2장 |
  | 티그리스 | 숫자 없음. 해적 또는 도망으로 사용 | 1장 |
  | 스컬킹 | 숫자 없음 | 1장 |
  | **합계** | **숫자 56장 + 특수 14장** | **70장** |

  숫자는 1부터 14까지이며 0 카드는 없습니다. 같은 숫자는 색마다 1장씩 전체 덱에 총 4장입니다. 예를 들어 7은 초록·노랑·보라·검정에 각각 1장씩 있습니다. 특수 카드에는 숫자가 없습니다. 초보자 룰북에도 같은 표와 예시를 제공합니다.
- 1~10라운드에 배분 장수를 1장씩 늘립니다. 덱이 부족하면 모든 참가자에게 같은 수를 배분하도록 제한하여 8명은 9·10라운드에도 8장씩 받습니다. 7명은 10장까지 가능합니다.
- 게임 시작 때 서버가 좌석을 한 번 무작위로 섞습니다. 첫 라운드는 1번 좌석부터 시작하고 이후 라운드 첫 선은 시계 방향으로 한 자리씩 회전합니다. 트릭의 승자가 다음 트릭의 선이며, 해당 선부터 고정 좌석 순서대로 시계 방향으로 카드를 냅니다. 무작위 좌석 배정은 이 온라인 버전의 시작 방식입니다.
- 예측은 손패 장수 이내의 정수이며 각자 제출합니다. 모두 제출할 때까지 다른 사람의 값은 전송하지 않습니다.
- 10라운드 이상 종료 시 단독 최고 점수가 우승합니다. 공동 1위가 있으면 연장합니다. 연장 배분은 최대 10장 및 덱 제한을 적용합니다.

## 카드 판정

- 숫자를 낼 때는 첫 색을 손에 가지고 있으면 해당 색을 따라야 합니다. 특수 카드는 언제든 제출할 수 있습니다. 첫 색이 없으면 다른 숫자도 가능합니다.
- 검정은 다른 숫자 색보다 높습니다. 같은 유효 색에서는 높은 숫자가 이깁니다. 다른 일반 색 숫자는 트릭을 이길 수 없습니다.
- 해적은 숫자와 인어보다 높고, 스컬킹은 해적보다 높으며, 인어는 스컬킹보다 높습니다. 세 종류가 함께 있으면 첫 인어가 이깁니다. 해적/인어 동종은 먼저 낸 카드가 이깁니다.
- 티그리스는 제출할 때 해적 또는 도망을 선언합니다.
- 도망으로 시작하면 다음 도망이 아닌 카드가 선 규칙을 정합니다. 캐릭터로 시작하면 숫자 색을 따르지 않습니다. 전부 도망이면 처음 낸 사람이 이깁니다.

## 점수

- 1 이상 예측 적중: 예측 × 20점. 실패: 예측과 획득 차이 × -10점.
- 0 예측 적중: 그 라운드의 배분 장수 × 10점. 실패: 배분 장수 × -10점.
- 일반 색 14 포획은 장당 10점, 검정 14는 20점입니다. 자신의 14도 포함합니다.
- 해적으로 인어 포획 시 장당 20점, 스컬킹으로 해적 포획 시 장당 30점, 인어로 스컬킹 포획 시 40점입니다. 제출 순서와 무관하며 승자의 포획에만 적용합니다. 티그리스는 선언한 종류로 판정합니다.
- 모든 보너스는 해당 라운드의 예측이 맞아야 지급합니다. 실패하면 보너스는 0점입니다.

## 온라인 진행과 미지원 옵션

예측 제한은 20초, 카드 제출은 각 차례 15초이며 만료 시 서버가 자동 행동합니다. 트릭 결과는 잠시 표시한 뒤 자동 진행하고, 라운드 결과는 서버가 결과를 확정한 시점부터 10초 뒤 자동으로 다음 라운드로 이동합니다. 결과 화면의 **스킵**에 현재 방에 남아 있는 사람 참가자의 3분의 2 이상(소수점 올림)이 동의하면 즉시 이동합니다. AI와 이미 퇴장한 사람은 투표 인원에서 제외합니다. 예를 들어 사람 3명은 2명, 4명은 3명, 5명은 4명의 동의가 필요합니다. 1인 AI 게임에서는 본인의 스킵으로 즉시 이동합니다. 중복 클릭은 한 표로 처리하고, 퇴장하면 인원과 유효 표를 다시 계산합니다. 최종 우승 결과는 자동으로 넘기지 않으며, 공동 1위의 연장 라운드에는 같은 자동 진행 규칙을 적용합니다. 이는 온라인 조작 방식입니다. 진행 중 나가면 AI로 대체하며, 새로고침은 같은 참가자로 복원합니다. 초기 화면의 초보자 룰북에서도 예시와 함께 같은 규칙을 설명합니다.

2인 고스트, 크라켄, 흰고래, 전리품, 해적별 능력, Rascal 등 대체 점수와 변형 장수는 포함하지 않습니다. 이 옵션은 로비에서 지원한다고 표시하지 않습니다.

## 서버 구현 원칙

클라이언트는 선택을 요청하고 서버가 허용 여부와 결과를 결정합니다. 손패는 본인에게만, 미공개 예측은 공개 시점 이후에만 전달합니다. 셔플은 서버의 암호학적 난수를 사용하고, 차례가 아닌 제출·소유하지 않은 카드·색 따르기 위반·중복 제출은 서버에서 차단합니다. 이전 게임 ID·라운드·트릭 번호의 지연 요청도 거부합니다.

라운드 종료 후 기본 점수·보너스·이번 점수·누적 점수를 보여주고, 다른 사람의 남은 손패는 공개하지 않습니다. 규칙 엔진은 HTTP 및 UI와 분리하여 카드 조합과 전체 게임 진행을 자동 검증합니다. AI는 자신의 손패와 공개된 트릭·자신의 예측/획득 수만 사용하며 다른 사람의 손패를 참조하지 않습니다.
