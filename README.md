# Skull King Online

친구들과 방 코드로 모여 즐기는 스컬킹 온라인 게임 프로젝트입니다.

개발 기준 폴더: `C:\Users\SSAFY\Documents\Codex\skull_king`

현재 **1단계: 온라인 대기실**입니다. 카드 게임 자체는 아직 플레이할 수 없습니다.

## 실행

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다.

```powershell
cd C:\Users\SSAFY\Documents\Codex\skull_king
npm start
```

접속: <http://127.0.0.1:4180/>. `start-local.cmd`를 더블 클릭하셔도 됩니다.

```powershell
npm test
```

## 현재 기능

- 이름 입력, 6자리 방 코드 생성, 코드 또는 초대 링크로 참가
- 최대 8명 대기실, 준비/취소, 1초 간격 상태 동기화
- 새로고침 후 같은 탭에서 참가 정보 복원
- 명시적으로 나갈 때 방장 승계, 마지막 참가자가 나가면 방 삭제
- 서버의 참가 인증·정원·이름·요청 검증
- 한국어 반응형 화면

5. 연결 복구·이탈 처리·모바일 실기기 검증

음성·영상은 카드 게임의 진행과 분리해서 추가합니다. 현재 코드는 해당 기능을 포함하지 않습니다.
