# Skull King Online

친구들과 방 코드로 모여 즐기는 스컬킹 온라인 게임 프로젝트입니다.

개발 기준 폴더: `C:\Users\SSAFY\Documents\Codex\skull_king`

현재 **기본 모드 게임 진행**을 지원합니다. AI를 포함해 3~8명이 참여하여 예측·카드 제출·점수 계산·최종 결과와 같은 방 다시 하기까지 진행할 수 있습니다.

## 현재 기능

- 이름 입력, 6자리 방 코드 생성, 코드 또는 초대 링크로 참가
- 최대 8명 대기실, 준비/취소, 1초 간격 상태 동기화
- 방장 전용 AI 플레이어 추가·개별 삭제, AI 자동 준비 (사람과 AI를 합쳐 최대 8명)
- 새로고침 후 같은 탭에서 참가 정보 복원
- 명시적으로 나갈 때 방장 승계, 마지막 참가자가 나가면 방 삭제
- 서버의 참가 인증·정원·이름·요청 검증
- 한국어 반응형 화면

혼자 테스트하려면 방을 만든 뒤 **AI와 바로 시작**을 누릅니다. AI를 채워 총 4명으로 시작합니다. 이미 3명 이상이면 **게임 시작**을 누릅니다. 방장은 준비 버튼을 별도로 누를 필요가 없고, 다른 사람 참가자는 준비해야 합니다. AI는 자동으로 예측하고 카드를 냅니다. 외부 AI 서비스 키는 필요하지 않습니다.

## 게임 진행

1. 방장 시작 → 서버 셔플 → 각자 비공개 손패 확인
2. 이길 횟수 입력 → 예측 제출 → 모두 제출하면 동시 공개
3. 내 차례에 카드 선택 → **내기**. 티그리스는 해적/도망을 선택합니다.
4. 트릭 승자가 다음 선을 잡습니다. AI는 자동 행동합니다.
5. 라운드 점수 확인 → 방장의 **다음 라운드**
6. 10라운드 후 단독 최고 점수가 우승입니다. 공동 1위면 연장합니다.
7. **대기실에서 다시 하기**로 같은 방의 참가자와 다시 준비합니다.

예측은 20초, 카드 제출은 내 차례마다 15초입니다. 시간이 지나면 서버가 손패와 공개 정보만으로 자동 제출합니다. 진행 중 명시적으로 나가면 AI가 대신하고, 방장은 남은 사람에게 승계합니다. 같은 브라우저·주소의 첫 화면에서 **이전 자리로 복귀**를 누르면 AI가 진행한 이후의 남은 손패·예측·점수와 같은 좌석으로 돌아옵니다. 새로고침은 같은 탭에서 자동 복원되며, 탭을 닫아도 복귀 버튼을 이용할 수 있습니다. 게임 중 사람이 모두 나가면 마지막 퇴장부터 10분간 방을 유지하고 그 뒤 정리합니다. 대기실에서 나가면 자리를 제거합니다.

초기 화면의 **처음이라면 · 룰북 읽기**에서 목표, 용어, 실제 조작 순서, 카드 우선순위와 점수 예시를 읽을 수 있습니다. 대기실과 게임 중에도 같은 룰북을 열 수 있습니다. 열어도 입력과 방 상태는 유지되며 게임 제한 시간은 계속 흐릅니다.

## 적용 규칙과 후속 개발

공식 2024 기본 규칙의 70장 덱과 기본 점수를 적용합니다. 8명은 9·10라운드도 각 8장씩 받습니다. 인어·해적·스컬킹·티그리스, 색 따르기, 14 카드와 캐릭터 포획 보너스를 포함합니다. 2인 전용 고스트, 크라켄·흰고래·전리품·해적 개별 능력과 대체 점수는 포함하지 않습니다. 상세 명세와 공식 자료는 `docs/RULES.md`에 있습니다.

후속 개발: 2인/확장 옵션, AI 전략 개선, 연결 상태 감지와 자리 만료, 실기기 검증, 필요에 따라 채팅·음성·영상·외부 HTTPS 배포.

음성·영상은 카드 게임의 진행과 분리해서 추가합니다. 현재 코드는 해당 기능을 포함하지 않습니다.

현재 방 상태는 메모리에만 저장되며 서버를 재시작하면 사라집니다. 복귀 정보는 같은 브라우저·주소에 마지막으로 참가한 자리 한 개를 저장합니다. 다른 기기·브라우저·주소에서는 복귀할 수 없습니다. 탭을 닫아도 즉시 AI로 전환하지 않으며 기존 예측·차례 타임아웃으로 자동 진행합니다. 즉시 AI에게 맡기려면 나가기 버튼을 이용합니다. 서버 재시작, 브라우저 저장 정보 삭제, 모든 사람 퇴장 후 10분 경과, 판 종료 후 방장이 대기실로 돌아가며 퇴장자를 정리한 경우에는 복귀할 수 없습니다. 연결 감지·자동 자리 만료, 요청 빈도 제한, 운영용 저장소와 외부 배포는 후속 단계입니다.
